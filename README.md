# IPv8 Lab

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)
[![SPDX](https://img.shields.io/badge/SPDX-Apache--2.0-brightgreen.svg)](https://spdx.org/licenses/Apache-2.0.html)

Experimental userspace IPv8 toolkit by Aleksei Aleinikov ([@LF3551](https://github.com/LF3551)).

This project explores IPv8 concepts through address parsing, packet generation,
routing simulation, and local userspace testbeds.
